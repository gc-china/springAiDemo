## 🚀 如何启动

### 1. 安装依赖

在Vue项目目录下运行：

```bash
cd web/spring-aidemo-frontend
npm install
```

### 2. 启动前端项目

```bash
npm run dev
```

### 3. 访问审计监控

启动后，在浏览器中：

1. 打开前端应用
2. 点击顶部导航栏的"审计监控"按钮
3. 即可看到审计监控面板

## 🔧 配置说明

### API接口

审计面板会调用以下后端API：

- `GET /api/audit/statistics` - 获取统计数据
- `GET /api/audit/trail` - 获取审计记录

### 错误处理

- 如果后端服务未启动，会显示友好的错误提示
- 图表组件采用动态加载，避免初始包过大
- 支持离线模式（显示空数据状态）
