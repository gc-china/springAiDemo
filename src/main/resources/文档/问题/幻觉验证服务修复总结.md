# 幻觉验证服务修复总结

## 问题描述

验证服务一直转圈导致对话停止，用户无法看到验证结果。

## 根本原因分析

1. **BeanOutputConverter 兼容性问题**：Spring AI 的 BeanOutputConverter 在某些情况下无法正确解析 LLM 返回的 JSON
2. **JSON 格式清理不足**：LLM 可能返回带有 Markdown 标记的 JSON，导致解析失败
3. **错误处理不够健壮**：缺少足够的降级策略和超时保护
4. **Reactive 流异常传播**：异常没有被正确捕获和处理

## 修复方案

### 1. VerifierService.java 修复

```java
// 移除 BeanOutputConverter，使用手动解析
String jsonResult = chatClient.prompt()
    .user(prompt)
    .options(ChatOptions.builder().temperature(0.0).build())
    .call()
    .content();

// 手动解析 JSON，避免 BeanOutputConverter 的问题
VerificationResult result = parseVerificationResult(jsonResult);
```

**新增方法**：

- `parseVerificationResult()`: 手动解析验证结果，处理各种格式问题
- 清理 Markdown 标记 (`\`\`\`json`, `\`\`\``)
- 使用 ObjectMapper 进行可靠的 JSON 解析
- 提供降级策略：解析失败时返回默认结果

### 2. RagService.java 修复

```java
// 同样移除 BeanOutputConverter
String response = chatClient.prompt()
    .user(rerankPrompt)
    .options(ChatOptions.builder().temperature(0.0).build())
    .call()
    .content();

// 手动解析重排序结果
List<Integer> selectedIndices = parseRerankResponse(response);
```

**新增方法**：

- `parseRerankResponse()`: 解析重排序响应数组
- 处理各种 JSON 数组格式
- 降级策略：返回 `[0, 1, 2]` 作为默认选择

### 3. AiService.java 优化

```java
.timeout(Duration.ofSeconds(12)) // 优化超时时间
.doOnSuccess(result -> logger.info("验证完成: passed={}, confidence={}", result.passed(), result.confidence()))
.onErrorResume(throwable -> {
    if (throwable instanceof TimeoutException) {
        logger.warn("验证服务超时，使用默认结果");
    } else {
        logger.error("验证服务异常，使用默认结果", throwable);
    }
    return Mono.just(new VerificationResult(true, 0.85, "验证超时或异常，基于通用知识回答", null));
})
```

**优化内容**：

- 超时时间从 15 秒优化为 12 秒
- 增强错误日志记录
- 简化错误处理逻辑
- 确保异常不会中断整个对话流

## 技术细节

### JSON 清理逻辑

```java
String cleanJson = jsonResult.trim();
if (cleanJson.startsWith("```json")) {
    cleanJson = cleanJson.substring(7);
}
if (cleanJson.endsWith("```")) {
    cleanJson = cleanJson.substring(0, cleanJson.length() - 3);
}
```

### 降级策略

1. **验证服务**：解析失败时返回 `{passed: true, confidence: 0.85, reason: "验证解析失败"}`
2. **重排序服务**：解析失败时返回前3个文档索引 `[0, 1, 2]`
3. **超时处理**：10-12 秒超时后自动返回默认结果

### 错误处理层级

1. **方法级别**：每个解析方法都有 try-catch
2. **服务级别**：Mono.onErrorResume 捕获 Reactive 异常
3. **流级别**：AiService 中的最终错误处理
