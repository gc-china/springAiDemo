# 中文乱码问题解决方案

## 问题描述

在文件预览时出现中文乱码，特别是 .txt 文件。这是一个常见的编码问题，通常由以下原因引起：

1. **文件保存编码与读取编码不匹配**
2. **Spring Boot 字符编码配置不正确**
3. **浏览器解析编码问题**
4. **Tika 解析器编码检测失败**

## 解决方案

### 1. Spring Boot 编码配置

#### 1.1 HTTP 编码配置

```yaml
# application.yml
spring:
  http:
    encoding:
      charset: UTF-8
      enabled: true
      force: true
```

#### 1.2 响应头编码增强


### 2. 编码检测工具类

#### 2.1 创建 EncodingUtils 工具类

```java
public class EncodingUtils {
    // 常见的中文编码
    private static final List<Charset> COMMON_CHARSETS = Arrays.asList(
            StandardCharsets.UTF_8,
            Charset.forName("GBK"),
            Charset.forName("GB2312"),
            Charset.forName("Big5"),
            StandardCharsets.ISO_8859_1
    );
    
    // 检测文件编码并读取内容
    public static String readFileWithCorrectEncoding(Path filePath) throws IOException;
    
    // 检测文本是否包含乱码
    public static boolean containsGarbledText(String content);
    
    // 清理 BOM 和其他编码问题
    public static String cleanContent(String content);
}
```

#### 2.2 编码检测策略

1. **优先尝试 UTF-8** - 现代标准编码
2. **回退到 GBK/GB2312** - 中文 Windows 系统常用
3. **尝试 Big5** - 繁体中文编码
4. **最后使用 ISO-8859-1** - 兜底编码

## 乱码检测规则

### 1. 替换字符检测

- `\uFFFD` (�) - Unicode 替换字符
- `锘�` - UTF-8 BOM 在 GBK 下的显示

### 2. 控制字符检测

- `0x00-0x08` - 空字符到退格
- `0x0B-0x0C` - 垂直制表符到换页符
- `0x0E-0x1F` - 其他控制字符

### 3. 常见乱码模式

- `涓枃` - "中文" 在 GBK→UTF-8 转换错误
- `鏂囨。` - "文档" 在编码转换错误

## 编码优先级策略

| 编码             | 使用场景          | 检测方法     |
|----------------|---------------|----------|
| **UTF-8**      | 现代标准，优先尝试     | 无乱码字符    |
| **GBK**        | 中文 Windows 系统 | 中文字符正常显示 |
| **GB2312**     | 简体中文标准        | 简体中文字符   |
| **Big5**       | 繁体中文          | 繁体中文字符   |
| **ISO-8859-1** | 兜底编码          | 最后尝试     |
