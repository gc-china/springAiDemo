# 问答应用引用预览下载修复方案

## 问题描述

用户反馈：在知识库管理页面中，文档的预览和下载功能正常工作，但在问答应用（ChatView）中，点击引用来源的预览和下载按钮无效。

## 根本原因分析

### 1. 引用信息获取方式不同

- **知识库页面**：直接调用后端 API 获取完整的文档信息，包含 `fileStatus` 等字段
- **问答应用**：通过解析 AI 回复文本提取引用信息，缺少关键的元数据字段

### 2. 前端预览逻辑依赖缺失字段

- 智能预览下载逻辑需要 `fileStatus` 字段来判断文档类型
- 文本解析方式无法获取 `fileStatus`、`mimeType` 等后端元数据

### 3. SSE 事件处理不完整

- 后端 RAG 服务已经构建了完整的引用元数据
- 但前端只处理了 `message` 和 `verification` 事件，没有处理引用信息

## 解决方案

### 1. 后端修改：在 SSE 流中发送引用信息

#### 1.1 RagService 增强元数据

```java
// 在 enhanceDocumentsWithSourceInfo 方法中添加文件状态判断
String fileStatus = "无文件";
if ("manual_ingest".equals(source)) {
    fileStatus = "纯文本";
} else if ("file_upload".equals(source)) {
    fileStatus = "文件正常";
}
metadata.put("file_status", fileStatus);
```

#### 1.2 AiService 发送引用事件

```java
// 在流结束后发送引用信息事件
.concatWith(Mono.defer(() -> {
    List<Map<String, Object>> citationsData = finalDocuments.stream()
            .map(doc -> {
                Map<String, Object> citation = new HashMap<>();
                citation.put("documentId", metadata.get("source_document_id"));
                citation.put("filename", metadata.getOrDefault("source_filename", "未知文件"));
                citation.put("fileStatus", metadata.getOrDefault("file_status", "未知"));
                // ... 其他字段
                return citation;
            })
            .collect(Collectors.toList());
    
    String citationsJson = objectMapper.writeValueAsString(citationsData);
    return ServerSentEvent.builder(citationsJson)
            .event("citations")
            .build();
}))
```

### 2. 前端修改：处理引用信息事件

#### 2.1 添加 citations 事件监听

```typescript
// 新增：处理引用信息事件
eventSource.addEventListener('citations', (e) => {
  if (isClosed) return;
  try {
    const citationsData = JSON.parse(e.data);
    const aiMsg = currentMessages.value[aiMsgIndex];
    
    // 将后端返回的引用数据转换为前端格式
    aiMsg.citations = citationsData.map((citation: any) => ({
      documentId: citation.documentId,
      filename: citation.filename,
      location: citation.location,
      downloadUrl: citation.downloadUrl,
      previewUrl: citation.previewUrl,
      fileExists: citation.fileExists,
      fileStatus: citation.fileStatus, // 关键字段
      mimeType: citation.mimeType
    }));
  } catch (err) {
    // 降级：使用文本解析
    const aiMsg = currentMessages.value[aiMsgIndex];
    aiMsg.citations = parseCitations(aiMsg.content);
  }
});
```

#### 2.2 更新 Citation 接口

```typescript
interface Citation {
  documentId: string;
  filename: string;
  location: string;
  downloadUrl: string;
  previewUrl: string;
  fileExists: boolean;
  fileStatus: string; // 新增：文件状态描述
  mimeType?: string;
  // ... 其他字段
}
```

### 3. 数据流架构改进

#### 修改前的数据流

```
RAG检索 → AI回复文本 → 前端文本解析 → 引用信息（不完整）
```

#### 修改后的数据流

```
RAG检索 → 构建完整元数据 → SSE流发送 → 前端接收完整引用信息
```

## 技术细节

### 1. 文档类型判断逻辑

| 来源标识            | 文件状态 | 预览方式   | 下载方式   |
|-----------------|------|--------|--------|
| `manual_ingest` | 纯文本  | 内容预览页面 | 生成文本文件 |
| `file_upload`   | 文件正常 | 直接预览文件 | 直接下载文件 |

### 2. SSE 事件类型

- `message`: AI 回复内容流
- `citations`: 引用信息（新增）
- `verification`: 幻觉验证结果

### 3. 错误处理策略

- 如果引用信息解析失败，降级使用文本解析
- 保持向后兼容性，不影响现有功能
